Drop your real files in here with these exact names and the page will pick
them up automatically (index.html already points at these paths):

  assets/logo.png              <- your JOY, IS Gaming logo (the yellow one)
  assets/banner.gif            <- System Siege RTS's animated banner (from itch)
  assets/youtube-banner.png    <- your YouTube channel banner
  assets/screenshots/1.png     <- screenshot 1
  assets/screenshots/2.png     <- screenshot 2
  assets/screenshots/3.png     <- screenshot 3
  assets/screenshots/4.png     <- screenshot 4

Until real files exist at those paths, the page shows a labeled placeholder
box instead of a broken image icon, so it's safe to publish before you've
added everything.

Optional:
  assets/favicon.png           <- if you add one, also add this to <head> in
                                   index.html:
                                   <link rel="icon" href="assets/favicon.png">
